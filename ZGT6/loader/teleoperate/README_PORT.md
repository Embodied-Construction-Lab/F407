# 装载机遥操作移植说明

本工程参考 `F407/receive_stick` 的串口摇杆接收、PCA9685 舵机/电调输出与 ADS1115 电位计读取；没有接入 IMU 或编码器。USART1 是 PA9 TX、PA10 RX，115200、8N1、异步模式；I2C1 是 PB6 SCL、PB7 SDA，连接 PCA9685（7 位地址 `0x40`）和 ADS1115（`0x48`）。I2C2 保持原 CubeMX 配置，当前程序未使用。

## 摇杆与输出

输入为以 `\n` 结束的直接 JSON，例如：

```json
{"X1":0,"Y1":0,"Z1":0,"X2":0,"Y2":0,"Z2":0}
```

| 输入 | 作用 | PCA9685 通道 |
| --- | --- | --- |
| Y2 | 大臂液压阀 | 0 |
| X2 | 铲斗液压阀 | 1 |
| X1 | 转向液压阀 | 2 |
| Y1 | 直行电机/电调 | 3 |
| X1、X2、Y2 任一非零 | 液压泵固定转速 | 4 |

Z1、Z2 仍须出现在输入帧中，以兼容 `receive_stick` 的六字段协议，但装载机暂不使用。输入死区是 0.15；阀门中位 90°，各轴正反向范围在 `Core/Inc/loader_control.h` 中分别定义。直行最大开度为 ±20%，液压泵激活时固定为 -30%；电调 0% 对应 1500 µs。超过 300 ms 未收到有效 JSON，五路输出回中/归零。PCA9685 目标频率 50 Hz，振荡器按 `receive_stick` 的 26.54 MHz 参数计算；实际频率仍需示波器校验。

## 电位计与回传

ADS1115 AIN0/1/2 分别为大臂、铲斗、转向。USART1 每 100 ms 发一行：

```text
pot,<ms>,<boom_mv>,<boom_angle_x10>,<bucket_mv>,<bucket_angle_x10>,<steering_mv>,<valid_mask>,<pca_ok>,<stick_fresh>\r\n
```

`valid_mask` 位 0/1/2 对应三路电压读取是否成功。大臂、铲斗角度沿用 `receive_stick/Core/Src/dwj_reader.c` 的电压标定，仅作初始参考，必须对装载机重新标定后才能用于闭环控制。转向电位计尚未标定，故只上报 mV，不输出伪造的角度。回传没有 IMU 或编码器字段。上电及实机首次验证时，请先断开执行器机械负载或确保安全停机，再核对串口、I2C ACK、PCA9685 50 Hz 波形、各轴方向及泵/电调中位。
